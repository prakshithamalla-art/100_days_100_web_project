# Math Quiz Game

An interactive math quiz game with multiple difficulty levels and timed questions.

## Features

- Random math questions (+, -, ×, ÷)
- Three difficulty levels (Easy, Medium, Hard)
- Timed questions (10-20 seconds based on difficulty)
- Score tracking with point system
- High score persistence (localStorage)
- Question counter
- Interactive feedback
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API

## How to Play

1. Select difficulty level (Easy, Medium, Hard)
2. Answer math questions by clicking the correct option
3. Score points based on difficulty
4. Complete all 10 questions
5. Try to beat your high score!

## Scoring System

- Easy: 10 points per correct answer
- Medium: 20 points per correct answer
- Hard: 30 points per correct answer

## Time Limits

- Easy: 20 seconds per question
- Medium: 15 seconds per question
- Hard: 10 seconds per question

## Project Structure

- index.html - Main HTML structure
- style.css - Styling and animations
- script.js - Quiz logic and functionality
